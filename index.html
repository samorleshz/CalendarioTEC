Actualizar el calendario

Cuando el TEC publique un calendario nuevo, la app puede tomarlo de un archivo calendario-tec.json publicado en una dirección web (por ejemplo GitHub Pages o un Gist). Pegue aquí esa dirección y presione Buscar actualizaciones.

Instalar la aplicación

En Windows y Linux: abra esta página en Chrome, Edge o Brave y use el ícono de instalar de la barra de direcciones. En Android: menú ⋮ → Instalar aplicación. Una vez instalada funciona sin conexión.
